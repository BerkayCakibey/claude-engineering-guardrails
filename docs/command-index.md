# Command Index

Commands are single-file entry points you can copy into `~/.claude/commands/`.

| Command | Purpose | Path |
|---|---|---|
| `bugfix` | Investigate and fix a bug using root cause analysis | [.claude/commands/bugfix.md](../.claude/commands/bugfix.md) |
| `code-review` | Multi-language code review. Usage: /code-review <target> | [.claude/commands/code-review.md](../.claude/commands/code-review.md) |
| `database-task` | Database operations: migrations, queries, schema changes, index optimization. Usage: /database-... | [.claude/commands/database-task.md](../.claude/commands/database-task.md) |
| `go-task` | Start a Go development task -- routes through the Go skill chain | [.claude/commands/go-task.md](../.claude/commands/go-task.md) |
| `infra-review` | Review infrastructure architecture -- AWS, GCP, K8s, Terraform | [.claude/commands/infra-review.md](../.claude/commands/infra-review.md) |
| `node-task` | Start a Node.js/TypeScript development task -- routes through the Node skill chain | [.claude/commands/node-task.md](../.claude/commands/node-task.md) |
| `ops-task` | Start a CloudOps task — Terraform change, EKS upgrade, or Kubernetes investigation | [.claude/commands/ops-task.md](../.claude/commands/ops-task.md) |
| `python-task` | Start a Python development task — routes through the skill chain | [.claude/commands/python-task.md](../.claude/commands/python-task.md) |
| `refactor` | Large-scale code refactoring with safety. Usage: /refactor <target> <goal> | [.claude/commands/refactor.md](../.claude/commands/refactor.md) |
| `security-review` | Run a security audit on the codebase -- OWASP, auth, secrets, IaC | [.claude/commands/security-review.md](../.claude/commands/security-review.md) |
| `tdd` | Generate tests, analyze coverage, and run TDD workflows. Usage: /tdd... | [.claude/commands/tdd.md](../.claude/commands/tdd.md) |
| `team` | Delegate a task to the team-lead orchestrator agent | [.claude/commands/team.md](../.claude/commands/team.md) |
